# Проверка читательской подборки, 17 октября 2026

Реализованы локальные решения/цитаты/заметки, сравнение двух–четырёх дел,
JSON-копия с объединением, Markdown/HTML/CSV со страницами и ссылками на сканы.
Метод, ограничения и схема: [READER.md](../READER.md).

## Сохранность и источники

Все 26 прежних файлов `lex/data/` побайтно совпадают с исходным снимком.
384 решения, 2152 пассажа, поисковые индексы, законодательство и сканы
не менялись. Личные записи не включаются в сборку, публичный API или git.
Три новых модуля добавляют около 62 КБ JavaScript до сжатия; тяжёлые тексты
для сравнения загружаются по запросу. Офлайн HTML — 27 516 616 байт;
цитаты/поиск работают без сети, изображения требуют интернета.

Цитата хранит буквальный оригинал, поле источника, Unicode-диапазон и SHA.
Прямая ссылка открывает ровно этот диапазон после проверки источника;
устаревшее место не подсвечивается. Страницы определяются по пересечению
диапазона с источниками пассажей, а не берутся целиком от соседнего окна.
Предупреждения о дефектах OCR сохраняются в подборке и выгрузках.

## Настоящий Chromium

`lex/eval/reader-browser.js` прошёл на локальной сборке:

- Сохранение из обычной выдачи и карточки без дубликатов.
- Выделение `[4300,4400)` текста 1905 № 1: оригинал совпал буквально,
  страницы ровно 4/5, полные сканы ровно `p0003_L` и `p0003_R`.
- Цитата заголовка открывается в заголовке, без переноса его координат на тело
  и без выдуманных страниц. В современной орфографии произвольное выделение
  отключено; кнопка возвращает оригинал для цитирования.
- Синтетический DOM с `Ѣ😀𐐀` и двумя параграфами проверяет перевод UTF-16
  в code points и сохранение `\n\n` между параграфами.
- Общая заметка, заметки к решению и цитате сохраняются при вводе и reload.
- Четыре формата скачиваются. HTML экранирует название с `<script>`;
  самостоятельная выгрузка читается без скриптов и автоматических изображений.
- JSON объединяет разные заметки, не дублирует цитаты; неизвестный ID,
  устаревшая цитата и недопустимый URL отменяют импорт без изменения подборки.
- Сравнение двух и четырёх дел из всех четырёх томов; пятый выбор отклоняется.
  Составная дата 1904 № 42 сохранена. На телефоне колонки перестраиваются
  вертикально, тёмная тема работает, горизонтального переполнения нет.
- Ссылка с неверным SHA показывает предупреждение и не выделяет чужое место.
- Автономный HTML сохраняет и открывает подборку в собственном хранилище.
- При отказе записи интерфейс сообщает о работе в памяти и позволяет
  скачать JSON; повреждённое содержимое не перезаписывается автоматически.
- Ошибок JavaScript и консоли нет.

Прежние `browser.js` и `laws-browser.js` также прошли: оба поиска, карта,
аналитика, все четыре тома, сканы, точные законодательные основания,
исторические ссылки, заголовки, мобильная/тёмная тема и standalone.
Функциональные проверки Chromium выполнены с локальными JSON; изображения
для компактной рабочей копии открывались с действующего публичного сайта.
