# Пояснения к пассажам 1897

Для поиска подготовлены краткие современные описания и понятия по
оригинальному тексту 641 пассажа из 100 решений. Используется подписка
Codex GPT-5.5, без Claude, отдельного платного API и облачного кредита.
Пояснения помечены как ИИ; они не заменяют исторический текст и не
представляют собой рекомендации по действующему праву.

В пакет включены идентификатор, SHA-256 текста, сам пассаж и заголовок
дела. Ответ должен различать факты, доводы стороны, вывод нижестоящего
суда и рассуждение Сената. В описании указывается, кому принадлежит
позиция. Пакеты возобновляются; готовый пакет повторно не запрашивается.
Одновременно работает только один процесс под блокировкой.

Перед импортом проверяется ровно ожидаемый набор идентификаторов,
отсутствие повторов, неизменённый SHA, непустое описание, 1–8 понятий
и буквальное наличие непрерывной цитаты в исходном пассаже. Техническая
проверка не доказывает правильность смысла: современные описания
вычитываются выборочно рядом с цитатой, а полной независимой юридической
редактуры всех 641 записей нет.

В проверке обнаружены шесть неточностей буквальной цитаты: «его» в №15,
«посему» в №31, регистр в №58 и №81, слово «палатою» в №64 и пропущенная
скобочная ссылка в №82. Они восстановлены по исходному тексту до импорта;
OCR и описания не переписывались. В одном ответе №66 был повреждён SHA:
после чтения полного пассажа и проверки соответствия текста SHA вручную
восстановлен из входного пакета. Сохранён отвергнутый ответ. Строгая
проверка не отключалась, автоматической подмены SHA нет. Тексты,
пояснения и изображения 1904/1905 сохранены.

Последний пакет из 17 записей прочитан полностью рядом с исходными
пассажами; в просмотренной выборке доводы сторон, выводы нижестоящих
судов и мотивировка Сената разделены. Для остальных пакетов выборочно
прочитано по три записи, кроме отдельных полных проверок описанных выше.
Это не независимая юридическая редактура всех 641 пояснений.

GPT-6 Luna был выбран для перехода на более лёгкую модель, но текущий
Codex CLI с подпиской ChatGPT ответил, что модель недоступна в этой среде.
Поэтому последний пакет также завершён на GPT-5.5; платный API не применялся.

Основной набор из 30 запросов и его пороги не изменяются. Дополнительные
пять вопросов [queries-1897.json](queries-1897.json) выбраны по чтению
оригинала до просмотра рангов: ответственность учреждения при выборе
сотрудников, неустойка при досрочном погашении займа, подставные требования
кредиторов, приобретательная давность общей земли, содержание супругов.
Автор уже читал часть пояснений этих решений при проверке, поэтому это
разработочная выборка доступности примеров, а не независимый тест.
Точность всей выдачи и обобщающее качество по ней не измеряются.

Оценка каждого подхода публикуется отдельно, вместе с прежней выборкой
и контролем поиска только по 1905. Результаты и SHA эталонов находятся
в `metrics*.json` и `metrics*.md`; эталонные цитаты не подгоняются под ранги.
