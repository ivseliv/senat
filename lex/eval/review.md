Аннотации всех 598 пассажей снабжены точной цитатой и SHA-256. Это механическая проверка происхождения, а не доказательство верной квалификации. При чтении выборки обнаружено и исправлено слишком широкое описание №93: дело касается различия полного товарища и вкладчика, а не ответственности до регистрации организации.

Для мнимых и притворных договоров сохранено различие из №105; словарь объединяет их только под современным поисковым запросом «фиктивные сделки». Слова «мнимая цель» из №9 сами по себе не дают совпадения с «мнимым договором»: расширенные фразы проверяются по порядку слов.

Проверка аннотаций дополнительно охватывает соответствующие пассажи указанных выше дел. Пояснения краткие и описывают обсуждение по цитате; одинаковые по теме пассажи могут иметь одинаковые пояснения. Не являются полным конспектом решения.
