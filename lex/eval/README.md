# Текущая оценка трёх томов

В корпусе 335 решений: 100 из 1897, 120 из 1904 и 115 из 1905. Неизменённый основной
набор из 30 запросов содержит эталоны только 1905 года. При поиске по трём
томам hybrid получил recall@5 **0,885**, recall@10 **0,962**, MRR **0,582**;
для 4 отрицательных запросов выдача пуста. Полная таблица:
[metrics.md](metrics.md), [metrics.json](metrics.json).

Контроль поиска только по 1905 сохраняет прежние 0,923 / 0,962 / 0,570;
общая проверка также проходит технический порог. Порог и эталон не снижены
и не подправлены. Новые места 1897 и 1904 могут конкурировать с прежними,
но не размечены в основном наборе. Сам факт улучшения не доказывает
релевантность всех новых результатов.
Для строгого сравнения нужна дополнительная независимая разметка юристом.

## Независимая выборка по трём томам

Новая [выборка из 30 запросов](queries-independent.json), по десять на каждый
том, не пересекается с прежними эталонами. Без настройки поиска hybrid даёт
recall@5 **0,100**, recall@10 **0,100**, MRR **0,078**. Это заметно хуже
старого целевого набора; детали протокола и ограничения — в
[отчёте](independent-2026-10.md). Этот результат не заменяет прежний
регрессионный контроль и не должен использоваться для подгонки словаря.

[queries-1904.json](queries-1904.json) добавляет 5 примеров, найденных Codex
при чтении исходного текста до просмотра их рангов. После полного обогащения
1904 hybrid покрывает 2 из 5 в первой пятёрке и 3 из 5 в первой десятке
(recall@5 0,400, recall@10 0,600, MRR 0,433).
[Таблица](metrics-1904.md) показывает все подходы. Это разработочная
выборка, а не отложенный тест: пояснения этих же мест подготовлены в той же
сессии, поэтому оценка не доказывает обобщающее качество.

Покрытие пояснениями ИИ: **641 из 641** пассажей 1897, **636 из 636** 1904 и
**598 из 598** 1905. Для каждого результата также работают исходный текст и
справочник 133 понятий;
покрытие видно в интерфейсе «О проекте». Внешний API не использовался.

## Выбор подхода на исходном корпусе 1905

Выбран **hybrid: справочник + обогащение пассажей**. Выбор сделан по recall@5,
затем MRR на 20 запросах `dev`, до просмотра 6 отложенных запросов `test`.
В этой части у hybrid recall@5 = **0,900**, recall@10 = **0,950**, MRR = **0,575**;
у справочника отдельно — 0,800 / 0,900 / 0,566, у обогащения —
0,750 / 0,850 / 0,534. Варианты сравниваются одним ядром и одинаковым BM25;
у гибрида кандидаты могут совпадать либо с оригиналом/старым выражением,
либо с современным описанием.

На отложенных 6 запросах hybrid дал 1,000 / 1,000 / 0,556.
На всех 26 положительных запросах — **0,923 / 0,962 / 0,570**.
На 4 отрицательных запросах каждый вариант дал пустую выдачу.
Эти значения относятся к поиску только в 1905. Контрольная таблица:
[metrics-1905.md](metrics-1905.md), [metrics-1905.json](metrics-1905.json).

## Эталон

[queries.json](queries.json) содержит 30 современных запросов: 20 для настройки,
6 отложенных и 4 отрицательных. Места выбраны вручную Codex при чтении исходного
распознанного текста, не по автоматически сгенерированным пояснениям. Для каждого
положительного запроса записаны решение, точные смещения и буквальная цитата
рассуждения Сената. Для «фиктивных сделок» — два места №105: различение мнимых и
притворных договоров и рассуждение о действительном намерении при притворной сделке.
Безденежность сама по себе не отождествлена с мнимостью: соответствующих
рассуждений в просмотренном томе для отдельного эталона не выявлено.

Релевантность проверяется по включению **всей эталонной цитаты** в найденный
пассаж. Совпадения только с номером решения недостаточно. Recall@k — доля
эталонных цитат, покрытых первыми k пассажами. Несколько перекрывающихся окон
не увеличивают число найденных эталонов. MRR — обратный ранг первого пассажа,
покрывающего хотя бы одну эталонную цитату, по полной выдаче. В средних каждый
запрос имеет одинаковый вес. Для отрицательных отдельно считается наличие
любого результата, а recall/MRR не вычисляются.

Это небольшой целевой набор с **неполной разметкой релевантности**, а не оценка
всей юридической практики: для многих запросов выбран один конкретный пример,
хотя другие решения тоже могут быть релевантны. Неразмеченный результат не
объявляется юридически ошибочным. Precision не измерена. Отрицательные примеры
относятся к современным техническим институтам и просты; для строгой проверки
нужны также трудные близкие, но нерелевантные вопросы. Юрист-владелец ещё не
проверял эталон; это явно отмечено и в [выборочной проверке](review.md).

## Воспроизведение

```bash
python3 lex/build.py --single
node lex/eval/run.js --split dev
node lex/eval/run.js --fail-on-regression
node lex/eval/run.js --years 1905 --fail-on-regression  # контроль прежнего корпуса
```

Скрипт сначала проверяет, что каждая цитата и её смещения совпадают с текущим
первоисточником, затем вызывает `concept.js`, используемый интерфейсом. Он
сохраняет SHA-256 набора запросов; повторный запуск воспроизводит таблицу.
Порог регрессионной проверки: recall@5 ≥ 0,65 и MRR ≥ 0,55 на положительной
части, пустая выдача для отрицательных. Это нижняя граница технического контроля,
не обещание качества для произвольного запроса.

Сервер, векторы и платные вызовы для прототипа не нужны. Справочник из 133
понятий и 1875 офлайн-аннотаций построены в текущей сессии. Инструмент импорта
возобновляется по контрольным суммам пассажей и разделяет аннотации по томам.
Вычитка словаря выборочная; следующие тома потребуют обогащения и расширения
эталона. Современные объяснения помечены как ИИ и всегда сопровождаются оригиналом.

## Несколько томов

При совместном поиске BM25 использует общие частоты документов и среднюю
длину пассажей по всем выбранным томам. Поэтому одинаковый текст получает
одинаковый вес в разных томах. Интерфейс и оценка используют `makeEngines`.

Основная таблица `metrics.md` оценивает текущий полный корпус. Параметр
`--years 1905` сохраняет отдельные `metrics-1905.json` и `metrics-1905.md`
для контроля прежней области поиска. При расширении корпуса неизменённые
эталоны 1905 могут опуститься из-за новых релевантных, но неразмеченных мест.
Следует публиковать обе оценки и объяснять различия, не менять цитаты ради
прохождения порога. Параметр `--suite eval/другой-набор.json` позволяет
оценить отдельную дополнительную выборку с такой же проверкой источников.

## Уточнение поиска 1897 и текущая оценка трёх томов, 3 октября 2026

Всего 335 решений и 1875 пассажей. Эталонные цитаты и пороги не менялись.
Добавлены пять контекстных понятий 1897 и исправлено сопоставление псевдонима,
когда служебное слово из него уже исключено из запроса. Контроль только 1905
сохранился: **0,923 / 0,962 / 0,570**. Общий hybrid достиг
**0,885 / 0,962 / 0,582** и проходит техническую проверку. На четырёх
отрицательных запросах выдача пуста.

Разработочная выборка из пяти запросов 1897 теперь дала hybrid recall@5
**1,000**, recall@10 **1,000**, MRR **0,733**. Это малая, не независимая
выборка: новые понятия подготовлены по её историческим контекстам, поэтому она
подтверждает доступность этих примеров, но не доказывает обобщающее качество.
Запросы, точные места и старый набор из 30 запросов не менялись. Отдельная
разработочная пятёрка 1904 дала 0,600 / 0,600 / 0,440.
