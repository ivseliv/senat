      Указатель показывает упоминания норм в доступных решениях, включая доводы сторон и нижестоящих судов. Привязки с буквальным основанием, прежние непроверенные и ссылки без установленного акта отмечены отдельно. Номер взят из OCR; редакция и текст статьи здесь не удостоверяются.

      Указатель участников

      Печатные указатели 1897, 1904 и 1905 годов: люди, семьи, организации и учреждения. Записи могут повторяться и не считаются уникальными людьми. Номера ведут к решениям; роль в деле и биография из указателя не выводятся. В вопросах без именованных участников записи нет.

      Как составлен каталог

      Тематическая разметка подготовлена с помощью ИИ по заголовкам, изложению и аннотациям пассажей; спорные места уточнялись по полному тексту. Одно дело может входить в несколько разделов. Это редакционная навигация: полнота всех возможных тем и юридическая экспертиза не заявляются. Во вкладках «Поиск», «По смыслу», «Карта», «Разборы» и «Аналитика» используется этот же каталог. Прежние автоматические метки сохранены в данных для проверки происхождения.

      Рабочая подборка

      Решения, оригинальные цитаты и ваши заметки — без регистрации. Они хранятся в этом браузере и не отправляются на сервер. Копия сайта в другом браузере или офлайн-файле имеет отдельную подборку.

      Заметки сохраняются при вводе. Скачивайте JSON-копию: очистка данных браузера удалит подборку. Редактируйте её в одном окне; изменения из других вкладок подхватываются при записи.

      Экспорт содержит заметки, оригинальные цитаты, печатные страницы и ссылки на сканы. Полные тексты дел и изображения в него не встраиваются.

      При импорте цитаты проверяются по текущему корпусу; страницы и ссылки определяются заново. Уже сохранённые заметки не заменяются.

      API и данные

      Версионированный статический API для исследований: решения, пассажи, привязки к сканам, указатель, законодательство и материализованные фильтры. Работает без ключа и сервера.

      JSON-файлы загружаются по прямым адресам. Параметры вроде ?year=1904 не выполняются на GitHub Pages; для этого есть отдельные годовые файлы и индексы.

      Что это

      Решения Правительствующего Сената по гражданским делам, переведённые в удобный для юриста вид: полнотекстовый поиск на современном языке, фильтры по теме, исходу, статье, составу присутствия, участникам и социальным группам, карточка решения со ссылками на связанные дела и сводная аналитика практики. Текст показывается в оригинальной дореформенной орфографии (ѣ, і, ѳ, ъ); переключателем «Орфография» его можно прочитать и в современной. Выбор запоминается. Поиск не зависит от орфографии: «вѣдомство» и «ведомство» найдут одно и то же.

      Доступные тома

      Пояснения ИИ могут быть подготовлены лишь для части фрагментов. Поиск по тексту и справочнику понятий работает и без них. Для решения с несколькими датами заседаний сохраняется составная дата из заголовка.

      Данные для исследования

      Готовый экспорт JSON и CSV содержит решения, пассажи, участников, ссылки на статьи и привязки к сканам. Манифест фиксирует состав и контрольные суммы файлов; ссылки на решения и пассажи можно использовать как постоянные. Для программного доступа есть версионированный API.

      Несколько слов
      находятся решения, где есть все слова, в любых формах: арендатор найдёт «арендатора», «арендатору».
      «В кавычках»
      точная фраза: "срок давности".
      -слово
      исключить слово: наследство -завещание.
      Современные термины
      «исполнитель» ↔ «душеприказчик», «ущерб» ↔ «убытки, вред», «залог» ↔ «заклад», «банкротство» ↔ «несостоятельность, конкурс». Расширение можно отключить; найденные дополнительные слова показываются над результатами.

      По смыслу

      Вкладка «По смыслу» ищет отдельные пассажи по современным понятиям и старым выражениям. Например, «фиктивные сделки» помогает найти обсуждение мнимых и притворных договоров. Подсветка отмечает слова запроса и найденные исторические выражения. Ссылка открывает нужное место в решении. Если совпадающих выражений нет, подсветка отмечает цитату пояснения ИИ. Номер страницы относится к печатному изданию; восстановленные по соседним колонтитулам номера помечены.

      «Пояснение ИИ» — краткое описание обсуждения, привязанное к цитате в пассаже. Это не текст Сената и не юридический вывод. Справочник не уравнивает современные и исторические институты. Отсутствие результата означает, что поиск не нашёл подходящий фрагмент в доступных томах.

      Ограничения

      • Текст получен автоматическим распознаванием (модель ИИ) и проверен выборочно. Ошибки возможны: сверяйте числа, номера статей и фамилии с изданием.
      • Тема, исход дела, названия кодексов и ссылки на прежние решения определены автоматически по правилам и могут быть неточны.
      • Пол, возраст, семейное положение, сословие, занятие и правовая роль отмечаются только при прямом обозначении в заголовке дела. Они не определяются по имени и не описывают всех участников решения.
      • Пока в корпусе не все годы (см. вкладку «Аналитика»); по мере распознавания томов данные добавляются.
      • Это исследовательский инструмент, а не юридическая консультация. Ссылайтесь на первоисточник.
