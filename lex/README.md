# Поиск и аналитика по решениям Сената (прототип)

Статический сайт для юриста: полнотекстовый поиск на современном языке, фильтры (год, тема, исход,
статья, сенатор/прокурор), карточка решения со ссылками на связанные дела, аналитика практики.
Работает без сборки и серверной части: любой статический хостинг (GitHub Pages).

> Входные данные для `build.py` (распознанные тома `ocr/<год>/volume.txt`) лежат в ветке `scans`; в `main` опубликован только готовый сайт.

## Как это устроено

```
ocr/<год>/volume.txt      распознанные тома (вход)
lex/build.py              разбор на решения, теги, индекс, аналитика  ->  lex/data/*.json
lex/lex.js                нормализация (старая орфография -> современная), стемминг, поиск (BM25)
lex/app.js, index.html    интерфейс
lex/dist/senat-lex.html   то же одним файлом с данными внутри (открывается двойным кликом)
lex/test_parity.py        проверка: нормализация в Python и JS даёт одинаковый результат
```

## Обновление после нового тома

```bash
python3 lex/build.py --single      # пересобрать данные и единый файл
python3 lex/test_parity.py         # (необязательно) проверить, что запрос и индекс совпадают
python3 -m http.server -d lex      # локальный просмотр: http://localhost:8000
```

## Что определяется автоматически (и может ошибаться)

- границы решений (по строке «Предсѣдательствовалъ…»; проверяется непрерывность нумерации, пропуски выводятся в консоль);
- дата, состав присутствия, исход (по резолютивной части), тема (по ключевым словам), упомянутые статьи и кодексы,
  ссылки на прежние решения («рѣш. 1887 г. № 16»), похожие решения (tf-idf);
- современная орфография: набор правил (ѣ→е, ъ на конце, -аго→-ого и др.), для чтения, не для цитирования.

Словарь «современный термин → старое выражение» (`GLOSSARY` в `lex.js`) расширяет запрос: «исполнитель» ↔ «душеприказчик».
