# Ссылки между решениями

Карточка показывает прежнее решение только при подтверждённом сочетании
**департамент → год → номер**. Год и номер сами по себе недостаточны:
например, гражданское решение 1896 №42 и решение Общего собрания 1896 №42
относятся к разным учреждениям. Отсутствующий том не подменяется имеющимся.

Для каждой найденной ссылки сохраняются оригинальная орфография, буквальная
цитата, окружающий контекст, Unicode-смещения, SHA-256 всего исходного текста,
печатные страницы и ссылка на точное место. Можно открыть цитату в карточке,
перезагрузить эту прямую ссылку и посмотреть скан соответствующей страницы.

## Как устанавливается связь

`precedents.py` читает опубликованные тексты без их изменения. Нормализация
сохраняет длину каждого символа, поэтому смещения относятся к оригиналу.
Поддержаны названия и сокращения гражданского и уголовного кассационных
департаментов и Общего собрания. Неясное или неподдержанное обозначение
остаётся неопределённым.

Департамент берётся из самой ссылки, тесно связанной вводной формулировки
или явно обозначенного перечня. В перечне допускаются несколько годов,
номеров и смена учреждения. Учтено обозначение после списка:
«1902 №36, 1903 №34 и 1904 №21 по общ. собранию…». Номера больше 600 не
отбрасываются. Следующий год, нумерованный довод и выпуск Собрания узаконений
не превращаются в номер судебного решения.

Упоминание в соседнем повествовании другого решения или общего собрания
акционеров не устанавливает департамент. Учреждение не выводится из темы,
авторства текущего решения, единственности года/номера в корпусе или сходства
юридического вопроса. Неясные ссылки сохраняются для проверки.

| Статус | Значение |
|---|---|
| `linked` | Единственное решение с тем же департаментом, годом и номером найдено. |
| `not_in_corpus` | Департамент указан, но такого решения в корпусе нет. |
| `department_unknown` | По поддержанным правилам учреждение не установлено. |
| `ambiguous_target` | Совпадение неоднозначно; переход не создаётся. |

Наличие ссылки не означает согласия Сената с процитированным доводом. Ссылка
может находиться в изложении позиции стороны или нижестоящего суда.
Окружающая цитата нужна именно для проверки этого различия. Извлечение
автоматическое и не претендует на полное восстановление всей сети ссылок.

## Данные и совместимость

- `data/precedents.json` загружается при открытии решения и входит в офлайн HTML.
- `export/precedents.json` и CSV содержат все упоминания с доказательствами.
- В API v1 контракт 1.1.0 добавляет `precedents/{year}.json` и `precedents` внутри решений.
- `cites` — устаревшие пары год/номер; сохранены для совместимости, для переходов непригодны.
- В `analytics.cited` убраны прежние индексы-переходы. `cited_decisions`
  учитывает учреждение и считает разные решения-источники; неопределённые
  учреждения не объединяются в тождественный прецедент.
- Поле `precedent_counts` показывает число упоминаний каждого статуса.

Постоянные ID имеющихся 384 решений не изменены. При дублировании ID сборка
останавливается: будущие одновременные тома разных департаментов за один год
потребуют отдельного решения о новых постоянных ID, а не слияния карточек.

## Проверки

```sh
python3 lex/build.py --single
python3 lex/test_precedents.py
python3 lex/test_build.py
python3 lex/test_parity.py
python3 lex/test_export.py
python3 lex/test_api.py
node lex/eval/precedents-browser.js
```

Для браузера используются установленные Playwright/Chromium; `NODE_PATH`,
`LEX_CHROMIUM`, `LEX_TEST_URL` задают окружение. `LEX_SCREENSHOTS` указывает
папку снимков. В компактной копии без растров `LEX_TEST_SCAN_URL` может
указывать на опубликованные изображения; офлайн HTML честно открывает сканы
на сайте и требует для них интернет.
