# Решения Гражданского кассационного департамента Правительствующего Сената

Статический исследовательский корпус дореволюционных решений для современного
юриста. Сейчас доступны три ежегодных тома: **1897, 1904 и 1905**, всего
**335 решений**. Оригинальная орфография сохранена; поиск понимает современное
написание слов.

Сайт: <https://ivseliv.github.io/senat/>. Книжная витрина в корне ведёт в
каталог и к карточкам решений. Полная рабочая база находится в
[`lex/`](lex/): понятийный поиск, карта связей, указатели участников, фильтры,
сканы и экспорт для исследований.

## Что есть в корпусе

- полный текст решений и карточки с темами, исходом кассации, статьями и
  составом присутствия;
- поиск по тексту, понятийный поиск по историческим формулировкам и прямые
  ссылки на пассажи;
- привязки к сканам: кадр с фрагментом, когда координаты подтверждены, и
  открытие полной страницы;
- указатели участников, поиск по законодательству, фильтры по процессуальному
  фокусу и социальным группам;
- [JSON/CSV-экспорт](lex/export/README.md) решений, пассажей, указателей,
  упоминаний норм и привязок к сканам.

Тексты получены автоматическим распознаванием. Числа, статьи законов и имена
следует сверять с изображением издания. Автоматические темы, исходы и пояснения
ИИ — навигационные средства, а не юридические заключения.

## Локальный просмотр

```bash
python3 -m http.server
```

Откройте <http://localhost:8000/>. Корневая витрина получает данные из
`lex/data/`; поэтому для неё нужен локальный HTTP-сервер. Собранный автономный
вариант базы находится в `lex/dist/senat-lex.html`.
