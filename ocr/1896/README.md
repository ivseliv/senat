# Общие собрания, 1896

Входной источник — локальный экспорт ABBYY FineReader: PDF на 89 страниц. Сам PDF
не хранится в Git. Его SHA-256, число страниц и ограничения зафиксированы в
[`source.json`](source.json).

`volume.txt` содержит 49 решений, № 1–49. Для построения использовался
`import_finereader.py`: он принимает только PDF с записанной контрольной суммой,
извлекает его текстовый слой и останавливается, если отсутствует одно из
проверенных начал решений. Начала и даты вручную сопоставлены с изображениями
PDF. У № 40 и № 46 строка заголовка не попала в текстовый слой; в `volume.txt`
добавлены лишь их номер и дата, прочитанные на скане. Содержание заголовков не
восстанавливалось.

```bash
python3 ocr/1896/import_finereader.py --pdf /путь/к/Решения\ Общих\ собраний\ 1896.pdf
python3 ocr/1896/build_page_map.py --pdf /путь/к/Решения\ Общих\ собраний\ 1896.pdf
```

`build_page_map.py` создаёт 89 файлов `pNNNN.txt` и `page-map.json`. В карте
записаны SHA-256 PDF и `volume.txt`, хеш текста каждого листа, диапазон каждого
фрагмента решения и его печатная страница. Для каждого фрагмента строка
FineReader находится **дословно** в тексте решения; при несовпадении скрипт
останавливается. Пропущенный или ошибочно распознанный колонтитул восстанавливается
только внутри серии, подтверждённой многими листами с обеих сторон; этот метод
сохраняется в данных и показывается пользователю. На первом листе печатного
номера нет: сайт показывает имя листа, а не выводит номер по соседней странице.

Изображения для поиска строятся только из этого же локального PDF через
`lex/build_scans.py --leaf-pdf`. У отдельных листов FineReader по-разному
упорядочивает две колонки в текстовом и координатном слоях. Карта с SHA-256
подтверждает физическую страницу; фрагмент вырезается лишь при строгом
координатном совпадении, иначе пользователь получает полную страницу.
