# Общие собрания, 1896

Входной источник — локальный экспорт ABBYY FineReader: PDF на 89 страниц. Сам PDF
не хранится в Git. Его SHA-256, число страниц и ограничения зафиксированы в
[`source.json`](source.json).

`volume.txt` содержит 49 решений, № 1–49. Для построения использовался
`import_finereader.py`: он принимает только PDF с записанной контрольной суммой,
извлекает его текстовый слой и останавливается, если отсутствует одно из
проверенных начал решений. Начала и даты вручную сопоставлены с изображениями
PDF. У № 40 и № 46 строка заголовка не попала в текстовый слой; в `volume.txt`
добавлены лишь их номер и дата, прочитанные на скане. Содержание заголовков не
восстанавливалось.

```bash
python3 ocr/1896/import_finereader.py --pdf /путь/к/Решения\ Общих\ собраний\ 1896.pdf
```

Текст дореформенный и получен автоматическим распознаванием. Он годится для
обычного полнотекстового поиска с обязательной сверкой по источнику. Для 1896
пока нет постраничных OCR-листов и опубликованных изображений, поэтому том не
участвует в поиске по смыслу и не показывает фрагменты сканов: сайт не будет
притворяться, будто такая привязка есть.
