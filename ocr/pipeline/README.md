# Пайплайн распознавания томов через Claude Code

Идея: скрипты готовят страницы, проверяют и собирают текст, а сами страницы распознаёт
`claude -p` (в пределах лимитов подписки). Требуется `poppler` (`brew install poppler`) и Claude Code.

## Порядок работы для одного тома

```bash
cd ~/projects/senat
PDF=$(ls ~/projects/senat_downloader/senat_pdfs/*1905.pdf | head -1)   # проверьте, что это нужный файл!

# 1. страницы -> work/1905 (для пилота: --pages 60-64, потом убрать)
python3 ocr/pipeline/prepare.py "$PDF" --out work/1905 --pages 60-64

# 2. распознавание (можно прерывать и запускать заново)
python3 ocr/pipeline/run.py work/1905 --out ocr/1905 --model sonnet --with-draft

# 3. проверка; --delete удаляет плохие страницы, тогда шаг 2 прогонит их заново
python3 ocr/pipeline/check.py work/1905 ocr/1905 --delete

# 4. сборка тома
python3 ocr/pipeline/assemble.py ocr/1905 --out ocr/1905/volume.txt
```

Полезные опции `run.py`: `--limit N` (сколько страниц за запуск), `--model opus|sonnet`, `--with-draft`
(подсказка из слоя ABBYY; для чистого сравнения качества запускайте без неё), `--dry` (только показать).

## Приоритет томов

В индексе сайта нет 1897–1910, 1912 и 1916 годов (см. `data/index.json`). Порядок: 1905 (пилот, самый маленький),
1904, 1897, 1898, 1899, 1900, потом остальные 1901–1910, 1912, 1916.

## Файлы

- `prompt.md` — инструкция модели для одной страницы (формат: `[[К: колонтитул]]`, `[[СНОСКИ]]`, `[?]`).
- `prepare.py` — PDF -> PNG страниц (развороты режутся пополам) + черновик из текстового слоя.
- `run.py` — цикл по страницам через `claude -p`, пропускает готовые, останавливается на лимите.
- `check.py` — поиск подозрительных страниц (пустые, отказы, расхождение с ABBYY по 4-граммам).
- `assemble.py` — склейка страниц в том, абзацы через границу страницы соединяются.
- `../compare.py` — точное посимвольное сравнение с ABBYY для выбранных страниц.
