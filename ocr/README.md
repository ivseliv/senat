# OCR-эксперимент: том «Решения Гражданского Кассационного Департамента за 1866 год»

Источник: `scans/..._o_1866.pdf` (Екатеринослав, 1911, 27 стр., растровый скан без текстового слоя).

- `claude_1866/pNN.txt` — распознавание по страницам (NN = номер страницы PDF), выполнено вручную моделью
  Claude по изображениям страниц (72 dpi-рендер, `pdftoppm`), орфография оригинала сохранена (ѣ, і, ѳ, ъ).
- `claude_1866.txt` — все страницы подряд.

Примечания:
- Переносы слов в конце строк склеены, абзацы разделены пустой строкой; колонтитулы «— N —» сохранены.
- Опечатки оригинала сохранены как напечатано (напр. «1886» вместо 1866 в № 70, «Шатанъ» в № 27, «стотьями» в № 75).
- Эталона для сравнения в репозитории пока нет: `data/src` содержит серию «Общее собрание», а не этот том.
